### AI Tools & Vibe Coding

I embrace the **vibe coding** philosophy — using AI as a collaborative partner in the development process. My toolkit includes:

- **Claude Code** — AI-powered coding assistant for complex problem-solving and code generation
- **GitHub Copilot** — Context-aware code completion and suggestions
- **Cursor** — AI-first code editor for rapid prototyping

I believe AI augments rather than replaces engineering skills. The key is understanding *when* and *how* to leverage these tools effectively while maintaining code quality and security standards.
